# Build Checklist

- [ ] Required vendor SDK is detected for the selected profile.
- [ ] Executable name and Windows icon are valid.
- [ ] Version and output folder are correct.
- [ ] Enabled Build Settings scenes are correct.
- [ ] Steam App ID is configured for Steam builds.
- [ ] Epic product, sandbox, deployment, Client ID, and Client Secret are configured for each Epic environment that will be built.
- [ ] Diagnostics contains no blocking errors.
- [ ] Build completes with no Unity Console errors.
- [ ] Output contains the active store SDK and no inactive store artifacts.
- [ ] Output folder is handed off for separate storefront delivery.
