Runtime and Editor API

One achievement call for Steam and Epic

using Aroko.StoreRelease.Runtime;
StoreAchievements.Unlock(GameAchievementIds.FirstWin);

The selected build supplies the matching provider. Unlocks are persisted before delivery, provider startup and delivery are retried automatically, and receipts are isolated per store environment.

StoreAchievements.Unlock

Pass a project-owned achievement ID configured identically in Steam and Epic. The API never requires game code to reference a vendor SDK.

public static class GameAchievementIds
{
    public const string FirstWin = "first-win";
}

StoreBuildRequest

A request contains only the cloned profile, version, and optional output path.

var request = new StoreBuildRequest(profile, "1.2.3", "Builds/Steam/1.2.3");
StoreOperationReport report = StoreBuildCoordinator.Build(request);

StoreReleaseProjectSettings

Contains the executable, icon, public store identifiers, Epic packaging templates, profiles, and Epic environments.

StoreOperationReport

Reports success, validation issues, resolved output, and a local diagnostic log.

IStoreEditorAdapter

Custom editor adapters can validate a profile and postprocess a completed player. Storefront delivery and developer-account authentication are outside this interface.
