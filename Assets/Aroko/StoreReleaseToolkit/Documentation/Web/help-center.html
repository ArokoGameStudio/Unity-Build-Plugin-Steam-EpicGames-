FAQ

Does the toolkit contact Steam or Epic?

The Editor performs local setup, validation, and builds only. It never uploads or signs into a developer account.

Why are vendor SDKs still required?

Store-specific packaging and runtime achievements use the selected vendor integration while excluding the inactive one.

How are achievements delivered?

The game runtime uses the selected store provider and the launched player's store session. Pending calls are saved and retried.

Glossary

Build handoff: the finished local folder produced for a separate delivery process.
